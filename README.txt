DSSSB IMAGE MOCK TEST

START ON A PC
1. Extract the entire ZIP to a folder.
2. Open index.html in Chrome or Edge.
3. Keep bank.js, loader.js, app.js, pdf.js, style.css and the packs folder together.
No installation, account or internet connection is required for the PC file version.

START ON A PHONE
The interface adapts to phone screens. For reliable mobile browser access, serve this
folder from your PC on the same Wi-Fi network:
- Install Python 3 on the PC if it is not already available.
- Run Start-Windows.bat on Windows, or run "python3 serve.py" on macOS/Linux.
- The server prints a local-network URL. Open that URL in the phone browser.
- Keep the PC/server running. Allow Python through the PC firewall for your private network.
The app can also be served by any ordinary static website host. Some phone file
managers do not allow HTML to load its accompanying scripts; use the network method.
Mobile layout was tested at 390px width, not on physical phones.

TEST RULES
- 100 questions: 20 each in Reasoning, General Awareness, Maths, English and Hindi.
- Choose a random mixed test, or one of the available original mock papers.
- Choose section order before starting each section.
- Once started, a section must be submitted before another can begin.
- Submitted sections cannot be reopened until the whole test is finished.
- Questions within the active section can be revisited and answers changed.
- One mark for a correct answer. Choose no negative marking or -0.25 for wrong answers.
- The 60-minute clock starts when the test is created, including section selection time.
- After 60 minutes, the clock turns red and counts extra time; it does not force submission.
- Section times include breaks, loading, and time away while the section is open.
- Results show score, extra time, section timing, accuracy, and the section taking most time.
- After all sections are submitted, download a PDF with images and correct/selected answers.
- Progress is saved in this browser on this device. Moving/renaming the folder, clearing
  browser storage or changing browser can lose progress. Keep one test tab open.

QUESTION BANK
5,405 included questions from all five supplied PDFs. There are 16 complete original
mock papers; other papers are disabled when their images/keys need review. Their
usable sections still contribute to random tests.

Questions remain original PDF pictures, including diagrams, symbols and Hindi text.
Printed answer keys are mapped to A/B/C/D; they are not independently fact-checked.
Where the printed key used 1/2/3/4, these were mapped to A/B/C/D.
Questions with asterisks instead of answers, uncertain boundaries, or conflicting
key recognition were excluded. Other source questions have not yet been imported.
See question-bank-report.json for detected exclusions and section counts. This report
is not an inventory of every question in the books. The complete PDFs are not included.
Image-based display avoids OCR transcription errors but cannot remove errors already
present in the source books. Spot checks and key cross-checks were performed; every
individual question has not been manually reviewed.

PRIVACY AND PORTABILITY
No accounts, analytics, remote fonts or online dependencies. Question packs load only
as needed. Browser storage stays on your device. The included server only serves this
folder and should be used on your trusted private network. Stop it with Ctrl+C.
